# استخدام Pages CMS

1. افتح https://app.pagescms.org وسجّل الدخول بحساب GitHub المصرح له على المستودع.
2. ثبّت Pages CMS GitHub App على مستودع `Mostafa-Ghanem/madar-albait-sa` إذا لم يكن مثبتًا.
3. اختر فرع `develop` أثناء المراجعة، ولا تعدّل `main` قبل الاعتماد النهائي.
4. افتح قسم **المقالات والأدلة**.
5. أكمل العنوان والوصف والقسم والكاتب والمراجع وحالة التحقق والمصادر قبل إزالة علامة **مسودة**.
6. حفظ المقال ينشئ Commit على GitHub ويبدأ Preview Build تلقائيًا في Cloudflare Pages.

## قواعد النشر

- التردد المتغير يحتاج مصدرًا رسميًا وتاريخ آخر تحقق.
- حالة `pending` تعني أن النتيجة لا تُعرض باعتبارها مؤكدة ميدانيًا.
- لا تستخدم H1 داخل نص المقال؛ العنوان يُولد من القالب.
- لا تحذف المصادر عند تعديل نص قديم.
- روابط الأفلييت تتطلب تفعيل حقل الإفصاح.
